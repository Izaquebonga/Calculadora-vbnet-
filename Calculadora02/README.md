calculadora02 - Visual Basic .NET

Descrição do Projeto
Este é um projeto de uma Calculadora Desktop funcional desenvolvida em Visual Basic .NET utilizando o framework Windows Forms. 

O projeto foi criado como um exercício prático para entender a manipulação de eventos, lógica de operadores matemáticos e interface gráfica no ambiente Visual Studio. A calculadora realiza operações básicas de aritmética e possui um sistema de tratamento de erros para divisões por zero.

 Funcionalidades
Operações fundamentais: Soma, Subtração, Multiplicação e Divisão.
Manipulação de números decimais (ponto flutuante).
Função de limpeza de memória e tela (C/CE).
Interface intuitiva e responsiva.


Instruções de Execução

Pré-requisitos
Para rodar ou editar este projeto, você precisará ter instalado:
1.  Visual Studio (versão 2019 ou superior recomendada).
2.  Carga de trabalho de **Desenvolvimento para Desktop com .NET.

Como Rodar o Projeto
1.  Clonar ou Baixar: Baixe os arquivos do repositório para sua máquina local.
2.  Abrir a Solução: Localize o arquivo com a extensão `.sln` (ex: `Calculadora02.sln`) e abra-o com o Visual Studio.
3.  Compilar: No menu superior, clique em `Compilação` > `Compilar Solução` (ou pressione `Ctrl + Shift + B`).
4.  Executar: Clique no botão verde "Iniciar" (ou pressione `F5`) para abrir a janela da calculadora.


Tecnologias Utilizadas
Linguagem: Visual Basic .NET (VB.NET)
Interface: Windows Forms (WinForms)
IDE: Visual Studio 2022
